# Companion Robot

MuJoCo simulation of a companion robot that detects an elderly person's fall and raises a simulated emergency alert (MDRIIA Group 02).

The whole project lives in [`Group_02_Kamakshi_Devanshi/`](Group_02_Kamakshi_Devanshi/README.md). Start there.

Setup:

```bash
python3.12 -m venv .venv && source .venv/bin/activate
pip install -r Group_02_Kamakshi_Devanshi/requirements.txt
python Group_02_Kamakshi_Devanshi/src/test_env.py
```
